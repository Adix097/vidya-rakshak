# 🎓 Student Dropout Prediction using Machine Learning

A beginner-friendly Machine Learning project that predicts whether a student is likely to **Drop Out** or **Graduate** based on demographic, socio-economic, macro-economic, and academic factors.

---

## 📌 Project Overview

Student dropout is a major challenge for educational institutions. Early prediction helps colleges identify at-risk students and provide timely support.

In this project, multiple Machine Learning algorithms are trained and compared to predict student outcomes.

---

## 🎯 Objective

Build a classification model that predicts whether a student will:

- 🎓 Graduate
- ❌ Drop Out

using historical student data.

---

## 📂 Dataset

The dataset contains **35 columns**, including:

### 1. Demographic Features
- Marital Status
- Gender
- Nationality
- Age at Enrollment
- International Student

### 2. Socio-Economic Features
- Mother's Qualification
- Father's Qualification
- Mother's Occupation
- Father's Occupation
- Scholarship Holder
- Debtor
- Tuition Fees Up to Date

### 3. Academic Features
- Course
- Application Mode
- Application Order
- Previous Qualification
- Semester Credits
- Semester Enrollments
- Semester Evaluations
- Semester Approved Subjects
- Semester Grades

### 4. Macro-Economic Features
- GDP
- Inflation Rate
- Unemployment Rate

### Target Variable
- Graduate
- Dropout
